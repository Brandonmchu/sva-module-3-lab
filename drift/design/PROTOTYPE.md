# Sky-blue planner design prototype

Approved by Jessica for sharing with Team Drift on 3 November 2026.

Run `npm start` inside `drift/`, then open:

`http://127.0.0.1:3004/design-prototype.html#trip/trip-001`

Use the port printed by the server if it differs. This is a separate visual exploration; the default landing page remains at `/`.

The prototype matches the landing page's airy sky-blue and turquoise palette, floating white/glass surfaces, Nunito typography, sunny yellow highlights, and warm panda accents. Its planner adds an illustrated skyline header, a larger red panda, actual group initials, and more expressive itinerary and people cards.

The prototype uses the same local product API and existing trip actions. Changes made through its forms update the local trip data. It does not add booking integrations, invitations, or new persisted fields.

Files: `public/design-prototype.html`, `public/design-prototype.css`, and `public/design-prototype.js`.
